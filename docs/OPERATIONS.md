# 器材租赁预约主管交班

1. 从总览核对 当天催确认席位的当班余额和已冻结单据。只在确认资源可用后试算额度。
2. 回读独立回放的覆盖数量、参考误差和关键分组。触发人工复核的单据按原因调阅源记录，再由班组另行确认。回放证据中的 `fragile_groups` 列出任一可能结局组合下越线的棚组，这些组整组转人工、不占席位；逐组 `worst_case_margin` 与 `censored` 给出最不利余量和撤仓未决单数。
3. 对照资源使用和逐单结果。系统保留组内上限和业务锁，跨班窗口留待下一班处理。
4. 当前方案确认后登记，记下版本号和运行标识。下一次试算以最近登记版本为基线，回查时按版本读取原证据。

行业动作名称为「加入催确认与释放队列」。同一方案重试仍回到原版本。
