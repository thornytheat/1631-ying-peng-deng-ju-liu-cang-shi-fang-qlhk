# 影棚灯具留仓释放业务规格

## 输入与时点

`day` 从演练档案起始日计数，`arrived` 表示入账日，`clock` 以 15 分钟为一格。测量在发生日之后一日内到达才可进入时点样本，超过窗口的补录留在隔离证据。跨日结果通过 `available` 回读，训练使用冻结日前已确认的最后一份回执。

业务组包括短片棚、产品棚、广告大棚、跨城外拍。同一 `case_id` 的同版本异值记录整笔隔离，重复记录只计一笔。

| 信号源 | 含义 | 接受范围 |
| --- | --- | --- |
| `lead_hr` | 取灯前剩余 h | 2 至 62 |
| `prepay` | 预付比例 % | 0 至 100 |
| `edits` | 预约改动次数 | 0 至 9 |
| `late_returns` | 近季超时归还 | 0 至 12 |
| `units` | 套件灯头数 | 1 至 12 |
| `replacement` | 备用灯头数 | 0 至 8 |
| `signed` | 合同已签 | 0 至 1 |

## 计算与裁决

使用分位分箱朴素贝叶斯，目标单位为 概率。数据冻结以 `as_of` 为锚点，选择截至第 `as_of-64` 日的历史，随后依次保留校准段、回放段和待裁决段。
训练样本的中位数与 MAD 用于共享缩放。组内样本数足够时，用组内中位数补齐非关键测量。以下特征按同一名次供回放和推理。

提前撤仓、撤仓前没收到客户结案回执的单据结局未知：不参与训练和校准，但进入回放队列。回放时新旧估法对同一笔未知结局按同一结果计分。棚组的新估法若在任一可能结局组合下超过现行布里尔分数容许线（新估法损失 ≤ 5/4 × 旧估法损失 + 0.015），该组就转人工，不占席位。临界裁决使用精确分数，舍入误差不能左右结论。晚到的撤仓记录若过了回放截止日，重算也不改当班名单。

| 派生特征 | 计算 |
| --- | --- |
| `payment_gap` | `1-prepay/100` |
| `edit_density` | `edits/9` |
| `prior_delays` | `late_returns/12` |
| `lead_time` | `lead_hr/62` |

关键测量不全、回放门限失败或组分布出现明显变化时进入人工复核。业务锁包括合同签订或无法维持套件完整性。最终分派受当天催确认席位总额和组内上限约束，使用额度守恒回读工作单。
